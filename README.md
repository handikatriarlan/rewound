# rewound

A one-minute browser game: follow the dot.

## Play

- Live: https://rewound.handikatriarlan.dev
- Controls: mouse/touch, or keyboard (`WASD` / arrow keys)

## Run locally

This project is a single static page (`index.html`).

1. Open `index.html` directly in a browser, or
2. Serve the folder with a static server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
